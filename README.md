# Russian-Kazakh-Code-switching-Corpus
Этот проект содержит корпус размеченных русско-казахских переключений кода. Корпус был разработан в рамках выпускной квалификационной работы Уалиевой Альмиры Эдуардовны. Материалом для этого исследования послужили комментарии из социальной сети, написанные в 2025 году. Каждый пример переключения был размечен по четырем классификациям: наличие переключения в высказывании, вид переключения по месту в высказывании, по мотивации употребления и по основному языку. 
Подробнее о разметке:

- наличие переключения:
есть;
нет;
- вид переключения по месту в высказывании:
внутреннее, если переключение представлено только 1–3 морфемами на другом языке в одном слове;
пограничное, если переключение представлено одним или несколькими словами на другом языке;
внешнее, если переключение представлено в виде нескольких слов и занимает более половины примера;
- вид переключения по мотивации:
ситуативное, если автор примера выбирает наиболее подходящий в данной ситуации язык;
метафорическое, если автор примера использует устойчивые слова или фразы;
- основной язык:
русский, если большая часть слов в примере на русском языке;
казахский, если большая часть слов в примере на казахском языке.


This project contains a corpus of marked-up Russian-Kazakh code switches. The case was developed as part of the final qualifying work of Almira Eduardovna Ualieva. The material for this study was comments from a social network written in 2025. Each switching example was categorized into four classifications: the presence of switching in the utterance, the type of switching by place in the utterance, by motivation of use, and by the main language. 
Learn more about markup:

- the presence of switching in the utterance:
yes;
no;
- the type of switching by place in the utterance:
internal, if the switching is represented by only 1-3 morphemes in another language in one word.;
borderline if the switch is represented by one or more words in another language.;
external, if the switch is presented in the form of several words and takes up more than half of the example.;
- type of motivation switch:
situational, if the author of the example chooses the most appropriate language in the given situation;
metaphorical if the author of the example uses stable words or phrases.;
- main language:
Russian, if most of the words in the example are in Russian.;
Kazakh, if most of the words in the example are in Kazakh.
